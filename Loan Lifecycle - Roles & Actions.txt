Complete Loan Workflow — Every Stage, Operation, Input & Action

  ---
  Stage 1: Inquiry

  Type: Sequential | Completion: Manual | Skippable: No
  Roles: Branch Manager, Loan Advisor
  Form Fields: None
  Actions: None

  Operation:
    → Auto-completed when quotation is converted to loan
    → For direct loan creation: loan creator clicks Complete

  ---
  Stage 2: Document Selection

  Type: Sequential | Completion: Manual | Skippable: No
  Roles: Branch Manager, Loan Advisor
  Form Fields: None
  Actions: None

  Operation:
    → Auto-completed when quotation is converted to loan
    → Documents auto-populated from quotation or customer type defaults

  ---
  Stage 3: Document Collection

  Type: Sequential | Completion: Manual | Skippable: No
  Roles: Branch Manager, Loan Advisor
  Form Fields: None (uses separate document collection UI)
  Actions: None

  Operation:
    → Advisor opens Documents tab
    → For each document:
        Mark as Received (customer provided)
        Mark as Rejected (not acceptable, provide reason)
        Mark as Waived (not needed for this case)
        Upload file attachment
    → Can add custom documents
    → Completion blocked until: ALL required docs are Received or Waived

  ---
  Stage 4: Parallel Processing (Container)

  Type: Parallel | Completion: Auto (when all sub-stages done) | Skippable: No
  Roles: None (container only, never assigned)

  Sub-stages execute in this order:
    4a: Application Number (must complete first)
        ↓
    4b: BSM/OSV Approval (must complete before 4c, 4d, 4e)
        ↓
    4c, 4d, 4e open in parallel:
        4c: Legal Verification
        4d: Technical Valuation
        4e: Loan Sanction Decision
        ↓
    ALL complete → Stage 4 done

  ---
  Stage 4a: Application Number

  Type: Sub-stage | Completion: Auto when fields filled | Skippable: No
  Roles: Branch Manager, Loan Advisor

  Form Fields:
  ┌─────────────────────┬──────────┬──────────┬─────────────────────────────────────────┐
  │ Field               │ Type     │ Required │ Notes                                   │
  ├─────────────────────┼──────────┼──────────┼─────────────────────────────────────────┤

  │ custom_docket_date  │ date     │ No       │ Only visible when offset = Custom (0)   │
  │ stageRemarks        │ textarea │ No       │ Optional remarks                        │

  Lifecycle:
    → Advisor assigned
    → Fills application number + selects docket timeline
    → If Custom: enters custom docket date
    → Stage auto-completes → opens BSM/OSV

  ---
  Stage 4b: BSM/OSV Approval

  Type: Sub-stage | Completion: Manual | Skippable: No
  Roles: Bank Employee

  Form Fields: None
  Actions: None

  Lifecycle:
    → Bank Employee assigned (auto from bank's default employee)
    → Performs BSM/OSV verification with bank
    → Clicks Complete
    → Completes → opens Legal Verification + Technical Valuation + Loan Sanction Decision

  ├───┼──────────────────────────────┼──────────┼───────────────────┼─────────────────────┤
  │ 1 │ Send to Bank                 │ Advisor  │ Save & Transfer   │ Bank Side           │

  ---
  Stage 4d: Technical Valuation

  Type: Sub-stage | Completion: Auto on save | Skippable: No
  Roles: Branch Manager, Office Employee

  Form Fields: Uses separate Valuation Form (LoanValuationController)
    - Property Type (6 options: residential_bunglow, flat, commercial, industrial, land, mixed)
    - Property Address
    - Latitude/Longitude (map picker)
    - Land Area + Rate per unit → Land Value (auto-calculated)
    - Construction Area + Rate per unit → Construction Value (auto-calculated)
    - Final Valuation = Land + Construction (auto-calculated)

  Actions: None (auto-completes when valuation form saved)

  Lifecycle:
    → Office Employee assigned (auto from branch default office employee)
    → Opens Valuation form
    → Fills property details, areas, rates
    → Saves form → stage auto-completes

  ---
  Stage 4e: Loan Sanction Decision

  Type: Sub-stage | Completion: Auto on action | Skippable: No
  Roles: Office Employee, Branch Manager, BDO

  Form Fields:
  ┌────────────────────┬──────────┬──────────┬───────────────────────────────────────────┐
  │ Field              │ Type     │ Required │ Notes                                     │
  ├────────────────────┼──────────┼──────────┼───────────────────────────────────────────┤
  │ decision_remarks   │ textarea │ No       │ Required for escalation only              │
  │ rejection_reason   │ textarea │ Yes      │ Only shown for Reject action              │
  │ escalation_history │ readonly │ No       │ Shows escalation chain                    │
  └────────────────────┴──────────┴──────────┴───────────────────────────────────────────┘

  Actions (escalation chain):
  ┌───┬──────────────────────────────┬──────────────────┬───────────────────┬─────────────────┐
  │ # │ Action                       │ Owner            │ Type              │ Required Fields │
  ├───┼──────────────────────────────┼──────────────────┼───────────────────┼─────────────────┤
  │ 1 │ Approve & Sanction Loan      │ Current Assignee │ Complete          │ None            │
  │   │ Sets is_sanctioned = true                                                            │
  ├───┼──────────────────────────────┼──────────────────┼───────────────────┼─────────────────┤
  │ 2 │ Escalate to Branch Manager   │ Office Side      │ Save & Transfer   │ decision_remarks│
  │   │ Transfers to Branch Manager                                                          │
  ├───┼──────────────────────────────┼──────────────────┼───────────────────┼─────────────────┤
  │ 3 │ Escalate to BDO              │ Advisor          │ Save & Transfer   │ decision_remarks│
  │   │ Transfers to BDO                                                                     │
  ├───┼──────────────────────────────┼──────────────────┼───────────────────┼─────────────────┤
  │ 4 │ Reject Loan                  │ Advisor          │ Complete          │ rejection_reason│
  │   │ Sets loan status = rejected, all stages locked                                       │
  └───┴──────────────────────────────┴──────────────────┴───────────────────┴─────────────────┘

  Lifecycle:
    → Office Employee assigned
    → Office Employee sees: [Approve] [Escalate to BM]
       If approves → is_sanctioned=true, stage completes
       If escalates → transfers to Branch Manager with remarks

    → Branch Manager sees: [Approve] [Escalate to BDO] [Reject]
       If approves → is_sanctioned=true, stage completes
       If escalates → transfers to BDO with remarks
       If rejects → rejection_reason required, loan rejected, ALL stages locked

    → BDO sees: [Approve] [Reject]
       If approves → is_sanctioned=true, stage completes
       If rejects → rejection_reason required, loan rejected, ALL stages locked

    On rejection:
      → loan.status = rejected
      → loan.rejected_at, rejected_by, rejected_stage, rejection_reason recorded
      → ALL pending/in_progress stages → status = rejected
      → All stages become read-only

  Form Fields: Handled by separate DisbursementController (not stage_form_fields)

  └───────────────┴───────────────────────────────────────────────────────────────┘

  Lifecycle:
    → Advisor fills disbursement form
    → Selects type: Fund Transfer or Cheque
    → Fund Transfer: enters account details → Save → loan status = completed
    → Cheque: enters cheque details → Save → advances to OTC Clearance

  ---
  Cross-Stage Rules

  Query System

  Every stage can have queries raised (can_raise_query = true)
  Pending queries block stage completion and action execution
  Flow: Raise → Respond → Resolve → Stage unblocked

  Auto-Assignment Priority

  1. Product Stage Config (branch/city/state-specific user)
  2. Bank-side: bank default employee → employer bank+branch → employer bank
  3. Office-side: default office employee for branch
  4. Advisor: loan creator (if advisor-eligible)
  5. Branch-based match
  6. Any active user with eligible role

  Loan Status Rules

  Approve (sanction decision)  → is_sanctioned = true
  Reject (BM/BDO only)        → loan rejected, all stages locked, read-only
  On Hold (loan creator only)  → processing paused
