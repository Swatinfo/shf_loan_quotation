## Post-upload order on the server

```bash
cd /home/admin/web/loans.shfworld.com/public_html

# 1. Pull vendor deps (new: spatie/activitylog, laravel/reverb, notification-channels/webpush)
composer install --no-dev --optimize-autoloader

# 2. Update .env — see notification_setup.md §2 for the block to add
#    REVERB_*, BROADCAST_REVERB_*, VAPID_* (generate via §3)

# 3. Cache config with new values
php artisan config:clear
php artisan config:cache
php artisan route:cache
php artisan view:clear

# 4. Run new migrations
php artisan migrate --force

# 5. Tell queue worker to pick up new code
php artisan queue:restart

# 6. Wire Nginx WebSocket proxy (VestaCP)
chmod +x deploy/setup-reverb-nginx.sh
sudo bash deploy/setup-reverb-nginx.sh         # interactive prompts

# 7. Install Reverb as systemd service — notification_setup.md §A.2
#    Copy the [Unit]/[Service] block, sudo systemctl daemon-reload, enable --now

# 8. Install cron line (scheduler drives queue + stale-read sweep)
sudo -u admin crontab -e
# * * * * * cd /home/admin/web/loans.shfworld.com/public_html && /usr/bin/php artisan schedule:run >> /var/log/shf/schedule.log 2>&1

# 9. Smoke-test
curl -sI -o /dev/null -w '%{http_code}\n' https://loans.shfworld.com/app/   # expect 400
curl -I https://loans.shfworld.com/sw.js                                     # expect 200

# 10. In browser: hard-reload, DevTools → Network → WS → expect 101 Switching Protocols.
#     Fire a test notification via tinker, confirm bell + OS notification.
```
