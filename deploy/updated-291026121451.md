**What this release brings**
- Partial disbursement lifecycle — new loan status `partial_completed`; *Mark Full* sets the loan amount.
- Payout base rules (PF + admin taken once, PF-based commission on GST-exclusive PF, insurance info-only, TDS on the total).
- Bank reconciliation: the Excel `product` column check, bank names / aliases per product, one-click
  **Change to X** product correction, re-run without re-uploading, `loan_amount` column renamed `disbursed_amount`
  (old files still work), loan numbers / A/c numbers link to the loan's Stages page.
- `payout:purge-runs` command (backs up the DB first, then clears past payout runs) — **not scheduled; do not run it unless asked**.
- Stage reset error handling (`LoanStageController`).

> **Golden rules**
> - Back up the live **database and code** first.
> - **Never overwrite the live `.env`** — edit `SHF_VERSION` in place only.
> - Migrations are forward-only: `php8.4 artisan migrate --force`. Never `migrate:fresh` / `refresh` / `rollback`.
> - No npm / Vite build — the frontend is plain files.
> - The server uses **`php8.4`** (plain `php` is not the right binary there).

## 2. Back up (mandatory)

```bash
cd /path/to/laravel-root            # the live project root
# Database
mysqldump -u <user> -p shf_all_operations | gzip > ~/backup_pre_updated_$(date +%Y%m%d_%H%M%S).sql.gz
# Code (the files this zip will overwrite)
unzip -Z1 updated-291026121451.zip | xargs -d '\n' tar -czf ~/code_pre_updated_$(date +%Y%m%d_%H%M%S).tar.gz --ignore-failed-read 2>/dev/null
```

Check both backup files exist and are not empty (`ls -lh ~/backup_pre_updated_* ~/code_pre_updated_*`).

## 7. Check it works

1. Log in, hard-refresh (Ctrl+F5).
2. **Payouts → Reconcile:** *Download template* has the columns `application_number, loan_acc_no, customer_name, product, cheque_number, disbursement_date, disbursed_amount, pf_amount, insurance_amount`. Run a reconcile — loan numbers show in orange and open the loan's Stages page in a new tab.
3. **Settings → Products & Stages → Edit product:** the *Bank names / aliases (optional)* field is there and saves.
4. **Payouts → Runs:** open a run — loan / A/c numbers link to Stages.
5. Open a partially disbursed loan — status and progress look right.
6. Look at `storage/logs/laravel.log` for new errors.

```bash
      resources/views/newtheme/payouts/_acc-link.blade.php resources/views/newtheme/payouts/_product-check.blade.php

```

The four migration files can stay — restoring the DB dump also restores the `migrations` table.
